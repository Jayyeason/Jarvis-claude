## 1. 设计语言

### 1.1 核心原则

- **克制**：不做炫酷动效，只做帮助用户感知状态的必要过渡
- **融合**：灵动岛胶囊与 macOS 菜单栏等高，视觉融为一体
- **原生**：字体、颜色、圆角全部跟随系统，不硬编码
- **专注**：每个面板只做一件事，信息密度适中

### 1.2 颜色

全部使用 macOS 语义颜色，自动适配深色/浅色模式，不硬编码任何颜色值。

```swift
// 背景
.background          // 主背景
.secondaryBackground // 次级背景（卡片）

// 文字
.primary             // 主文字
.secondary           // 次级文字（说明、标签）

// 强调
.accentColor         // 系统强调色（跟随用户系统设置）

// 状态
Color.green          // 成功
Color.red            // 错误/警告
Color.orange         // 注意

// 特定语义
Color(.separatorColor)   // 分割线
Color(.controlBackground) // 输入框背景
```

### 1.3 字体

全部使用 SF Pro（系统默认），不引入任何自定义字体。

```swift
.font(.system(size: 13))           // 正文
.font(.system(size: 11))           // 说明文字
.font(.system(size: 15, weight: .semibold))  // 标题
.font(.system(size: 22, weight: .bold))      // 大标题
.font(.system(.caption))           // 标注
.font(.system(.footnote))          // 小字
```

### 1.4 圆角

```swift
10  // 主面板、大卡片（与系统 popover 一致）
8   // 卡片内元素、按钮
6   // 小标签、小按钮
4   // 极小元素
```

### 1.5 间距（8pt 网格）

```
4pt   极小间距（icon 与文字）
8pt   元素内部间距
12pt  元素之间间距
16pt  区块之间间距
20pt  面板内边距
```

### 1.6 面板尺寸

```
灵动岛胶囊高度：= NSStatusBar.system.thickness（22-24pt，与菜单栏等高）
面板宽度：300pt（固定）
面板最大高度：440pt（超出内部滚动）
面板最小高度：随内容自适应
```

### 1.7 背景材质

```swift
NSVisualEffectView(material: .popover)  // 所有面板背景
// 自动适配深色/浅色模式
// 带有毛玻璃效果，与系统 popover 一致
```

## 2. 灵动岛胶囊

### 2.1 状态说明

| 状态 | 触发条件 | 外观 |
|------|---------|------|
| 静默态 | 默认 | 只有 Jarvis 图标 |
| Hover 态 | 鼠标移入 | 横向展开，显示功能按钮 |
| 推理中 | Agent 推理时 | 输入框右侧显示 ProgressView |
| 云端路由 | 使用云端 API 时 | 右下角小云图标 ☁️ |
| 离线 | 无网络时 | 图标变灰 |

### 2.2 静默态

```
┌──────────┐
│  [J图标]  │
└──────────┘

高度：= menuBarHeight（22-24pt）
宽度：36pt
背景：透明（融入菜单栏）
图标：Jarvis 像素风 Logo，16×16pt
```

**Jarvis 图标规格**：
- 16×16pt，圆角矩形容器（圆角 3pt）
- 紫色背景（accentColor）
- 白色 "J" 字符，SF Pro Bold
- 深色/浅色模式均使用此配色（强调色背景不反色）

### 2.3 Hover 态

鼠标移入后，胶囊平滑横向展开（easeOut 0.2s），显示功能按钮：

```
┌─────────────────────────────────────────────────────────────┐
│ [J]  [💬 对话]  [📸]  [⚡Auto ▾]  [🧠 Qwen3 1.7B ▾]  [📋] │
└─────────────────────────────────────────────────────────────┘

高度：= menuBarHeight（与静默态相同）
宽度：展开后约 380pt
背景：NSVisualEffectView(.popover)，圆角 6pt
```

**按钮规格**：

| 按钮 | 宽度 | 图标 | 说明 |
|------|------|------|------|
| J 图标 | 28pt | Jarvis Logo | 无点击行为 |
| 对话 | 52pt | 💬 + 文字 | 展开对话面板 |
| 截图 | 28pt | 📸 | 触发截图，等同 ⌘⇧J |
| 推理模式 | 64pt | ⚡Auto ▾ | 弹出模式选择 |
| 模型选择 | 96pt | 🧠 模型名 ▾ | 弹出模型列表 |
| Task List | 28pt | 📋 | 展开待办列表 |

按钮样式：
```swift
// 文字颜色：.primary（hover 时略变深）
// 背景：透明，hover 时显示圆角矩形背景
// 按压：opacity 0.7，easeOut 0.1s
// 分隔：各按钮之间 8pt 间距，无分割线
```

### 2.4 推理模式下拉（⚡Auto ▾）

点击后在胶囊下方弹出：

```
┌─────────────────────────┐
│  推理模式                │
│  ● Auto（智能路由）      │
│  ○ 端侧                 │
│  ○ 云端                 │
└─────────────────────────┘

宽度：160pt
圆角：8pt
背景：NSVisualEffectView(.menu)
```

- 选中项显示 ●，未选中显示 ○
- 点击立即切换，通过 @AppStorage 同步到设置页和菜单栏

### 2.5 模型选择下拉（🧠 模型名 ▾）

```
┌──────────────────────────────┐
│  端侧模型                    │
│  ● Qwen3 1.7B               │
│  ○ Gemma 4 E4B               │
│  ○ Qwen3 0.6B   ⬇ 未安装     │
│  ─────────────────────       │
│  云端模型                    │
│  ○ claude-sonnet-4-5  API   │
│  ○ gpt-4o             API   │
│  ○ deepseek-chat       API   │
│  ─────────────────────       │
│  ⚙ 管理模型...              │
└──────────────────────────────┘

宽度：200pt
分组：端侧模型 / 云端模型（系统 Divider 分割）
```

- 已安装模型正常显示，未安装显示 ⬇ 未安装（灰色）
- 切换端侧模型时：按钮文字变为"加载中…"，加载完成后更新
- 点击"⚙ 管理模型…"打开设置页模型管理区块

## 3. 对话面板

### 3.1 布局结构

```
┌──────────────────────────────────────────────┐  ← 与胶囊紧贴，从胶囊下方展开
│                                              │
│  [消息气泡区域，纵向滚动]                     │
│                                              │
│  Jarvis: 今天有两个日程需要确认...            │
│                                              │
│  You: 明天下午3点开会                         │
│                                              │
│  Jarvis: 大概持续多久？                       │
│  [30分钟] [1小时] [1.5小时] [2小时]          │
│                                              │
├──────────────────────────────────────────────┤
│  ┌────────────────────────────────────────┐  │
│  │ 输入消息，或粘贴 / 拖拽图片...          │  │
│  │                                        │  │
│  │ [🖼 screenshot.jpg ✕]                 │  │  ← 图片预览
│  └────────────────────────────────────────┘  │
│                                  [↵ 发送]    │
└──────────────────────────────────────────────┘

面板宽度：300pt
内边距：16pt
输入框：圆角 8pt，背景 controlBackground
```

### 3.2 消息气泡

```swift
// 用户消息（右对齐）
HStack {
    Spacer()
    Text(message)
        .padding(.horizontal, 12)
        .padding(.vertical, 8)
        .background(Color.accentColor)
        .foregroundColor(.white)
        .cornerRadius(16)
        .cornerRadius(4, corners: .topRight)  // 右上角小圆角
}

// Jarvis 消息（左对齐）
HStack {
    Text(message)
        .padding(.horizontal, 12)
        .padding(.vertical, 8)
        .background(Color.secondaryBackground)
        .foregroundColor(.primary)
        .cornerRadius(16)
        .cornerRadius(4, corners: .topLeft)
    Spacer()
}
```

### 3.3 图片输入

- 支持 `⌘V` 粘贴剪贴板图片
- 支持拖拽图片文件到输入框
- 添加后显示缩略图（40×40pt，圆角 6pt）+ 文件名 + ✕ 移除
- 发送时压缩为 JPEG（最大边 1024px，quality 0.85）

### 3.4 推理中状态

```swift
// 输入框发送按钮替换为 ProgressView
ProgressView()
    .scaleEffect(0.8)
    .frame(width: 28, height: 28)

// 发送按钮在推理中禁用
// 不阻断用户查看历史消息
```

## 4. 确认卡片（ConfirmationCard）

识别完成后展示，用户确认/编辑/丢弃。

### 4.1 日程类型

```
┌──────────────────────────────────────────────┐
│  📅  日程识别结果                             │  ← 标题栏，accentColor 左边框
├──────────────────────────────────────────────┤
│                                              │
│  标题    与王总季度复盘                [编辑] │
│  时间    明天 14:00 – 15:30          [编辑] │
│  地点    国贸三期  ✓ 已获取坐标       [更改] │
│  参与人  王总、张副总                 [编辑] │
│  提醒    提前 30 分钟                        │
│                                              │
├──────────────────────────────────────────────┤
│  [✓ 写入日历]              [编辑]  [丢弃]    │
└──────────────────────────────────────────────┘
```

### 4.2 提醒事项类型

```
┌──────────────────────────────────────────────┐
│  ✅  提醒事项识别结果                         │
├──────────────────────────────────────────────┤
│                                              │
│  标题    交期末 PPT                  [编辑] │
│  截止    4月20日 22:00               [编辑] │
│  优先级  中                          [编辑] │
│  备注    —                                   │
│                                              │
├──────────────────────────────────────────────┤
│  [✓ 写入提醒]              [编辑]  [丢弃]    │
└──────────────────────────────────────────────┘
```

### 4.3 样式规格

```swift
// 卡片背景
RoundedRectangle(cornerRadius: 10)
    .fill(Color.secondaryBackground)

// 左侧强调条
Rectangle()
    .fill(Color.accentColor)
    .frame(width: 3)

// 字段行
HStack {
    Text(key)       // 灰色，11pt，固定宽度 48pt
        .foregroundColor(.secondary)
        .frame(width: 48, alignment: .leading)
    Text(value)     // 主色，13pt
    Spacer()
    Button("编辑") { ... }  // 次级按钮，11pt
        .buttonStyle(.plain)
        .foregroundColor(.accentColor)
}
.padding(.vertical, 6)
Divider()  // 字段间分割线

// 主操作按钮
Button("✓ 写入日历") { ... }
    .buttonStyle(.borderedProminent)
    .controlSize(.regular)

// 次要按钮
Button("编辑") { ... }
    .buttonStyle(.bordered)
Button("丢弃") { ... }
    .buttonStyle(.plain)
    .foregroundColor(.secondary)
```

### 4.4 写入成功反馈

```
写入完成 → 卡片淡出（opacity 0，easeOut 0.2s）
→ 灵动岛胶囊短暂显示 ✓ 图标（0.8s）
→ 恢复静默态
```

信息缺失时弹出，让用户补充。

### 5.1 布局

```
┌──────────────────────────────────────────────┐
│  ℹ️  需要补充一些信息                         │
│  已识别的内容已预填                           │
├──────────────────────────────────────────────┤
│                                              │
│  标题 *                                      │
│  ┌────────────────────────────────────────┐  │
│  │ 与王总开会                             │  │  ← 预填（灰色）
│  └────────────────────────────────────────┘  │
│                                              │
│  开始时间 *                            ⚠️   │  ← 缺失字段高亮
│  ┌────────────────────────────────────────┐  │
│  │ 选择日期和时间...                      │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  地点（可选）                                │
│  ┌────────────────────────────────────────┐  │
│  │ 输入地点...                            │  │
│  └────────────────────────────────────────┘  │
│                                              │
├──────────────────────────────────────────────┤
│                      [取消]   [确认并写入]    │
└──────────────────────────────────────────────┘
```

### 5.2 字段样式

```swift
// 预填字段（已识别）
TextField("", text: $value)
    .background(Color.accentColor.opacity(0.05))  // 轻微强调背景
    .overlay(
        RoundedRectangle(cornerRadius: 6)
            .stroke(Color.accentColor.opacity(0.3), lineWidth: 1)
    )

// 缺失字段（需要填写）
TextField("", text: $value)
    .background(Color.orange.opacity(0.05))
    .overlay(
        RoundedRectangle(cornerRadius: 6)
            .stroke(Color.orange.opacity(0.6), lineWidth: 1.5)
    )
// 旁边显示 ⚠️ 图标

// 可选字段（普通）
TextField("", text: $value)
    .background(Color.controlBackground)
    .overlay(
        RoundedRectangle(cornerRadius: 6)
            .stroke(Color.separatorColor, lineWidth: 1)
    )
```

## 12. 动效规范

### 12.1 参数

```swift
// 面板展开/收起（主要过渡）
Animation.easeOut(duration: 0.2)

// 内容出现
Animation.easeOut(duration: 0.15)

// 按钮按压
Animation.easeOut(duration: 0.1)
```

### 12.2 具体应用

| 场景 | 动效 | 说明 |
|------|------|------|
| 胶囊 hover 展开 | easeOut 0.2s，横向展宽 | 不做弹跳，不做过冲 |
| 胶囊 hover 收起 | easeOut 0.2s，横向收窄 | 同上 |
| 面板从胶囊展开 | easeOut 0.2s，从胶囊下方向下展开 | opacity 0→1 + height 0→目标 |
| 面板收起 | easeOut 0.15s，向上折叠 | opacity 1→0 + height→0 |
| 消息气泡出现 | easeOut 0.15s | offset Y 8→0 + opacity 0→1 |
| 按钮按压 | opacity 1→0.7，easeOut 0.1s | 不做 scale 缩放 |
| 写入成功 | 卡片 opacity 1→0，easeOut 0.2s | 胶囊显示 ✓ 0.8s |

### 12.3 无障碍

```swift
// 检测减少动态效果设置
if NSWorkspace.shared.accessibilityDisplayShouldReduceMotion {
    // 跳过所有过渡动效，直接显示/隐藏
    // 不使用 withAnimation
}
```

### 12.4 禁止事项

- ❌ 不做弹簧过冲（spring with overshoot）
- ❌ 不做 3D 翻转
- ❌ 不做逐行错落淡入
- ❌ 不做 scale 缩放按压反馈（用 opacity 代替）
- ❌ 不引入任何第三方动效库
